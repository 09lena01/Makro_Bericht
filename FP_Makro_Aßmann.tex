	\section{Methods}
	Within this work a variety of methods have been used. In \autoref{chapter:introduction}, some of the theoretical background for the reactions has been displayed, whereas the focus lies on the analytical aspects in this chapter. Different instruments have been used for monitoring the reaction course, as well as the chemical and physical properties of the monomers and polymers. The following sections give more insight on the selected methods and for some of them a description of the handling of the analysis data to obtain or display results.\\
	For writing this report, the translation tool \citetitle{noauthor_deepl_nodate} has been used for formulaic purposes.\cite{noauthor_deepl_nodate}
	\subsection{\glsentryshort{NMR}}
	The technique \gls{NMR} spectroscopy can be used to determine the chemical composition, and by that also the purity, of chemicals, to obtain the conversion of a and monitor the polymerization reaction.\\
	For the analysis, \textsuperscript{1}\textit{H}-\gls{NMR} measurements were performed by the \gls{CEMSA} on the \SI{600}{\mega\hertz} spectrometer. The results have been displayed and analyzed via the software MestReNova v17.0.1 which has been obtained through the chemistry department at Heinrich Heine University.
	\subsubsection{\glsentryshort{DOSY}}
	\Gls{DOSY} is a form of \gls{NMR} spectroscopy wherein the different signals are measured as a function of their chemical shift as well as their \gls{D}. This allows the differentiation between different molecules within a mixture which makes it a powerful analysis for analyzing block copolymers. Within the \gls{CEMSA}, the measurments have been performed on the \SI{600}{\mega\hertz} Evo Neo spectrometer. For the analysis, the software TopSpin 5.0.0 Processing by Bruker has been used. The software can be acquired through the academic processing license on the Bruker website.\cite{noauthor_topspin_nodate}\\
	The analysis of \gls{DOSY} spectra can be done the following way:
	\begin{enumerate}
		\item Make a copy of the folder with the raw data
		\item Navigate to "\textit{/pdata/1}" within the copied raw data folder and localize the file called "\textit{2rr}"
		\item Open TopSpin
		\item Drag and drop the file "\textit{2rr}" into TopSpin \newpage
		\item Enter the following commands into the command line after the previous one is done:
		\begin{enumerate}
			\item xf2
			\item abs2
			\item eddosy
			\item setdiffparm
			\item dosy2d
		\end{enumerate}
		\item TopSpin can be closed once the commands have been run and MestReNova can be opened
		\item The edited folder with the data can be dragged and dropped into MestReNova
		\item In the \textit{Stacked} tab, the button \textit{DOSY Plot} needs to be pressed
		\item The display of the spectra can be edited via the \textit{Properties} window as usual
	\end{enumerate}
	\subsection{\glsentryshort{SEC}}
	\Gls{SEC} is an analysis method to characterize polymers in regard to their molecular weight. This provides information on the molar mass distribution and characteristic values, such as the \gls{Mn}, \gls{Mw} and the \gls{dispersity}.\\
	The measurements for the \gls{SEC} analysis were performed on the instruments within the Chair of Macromolecular Chemistry at \gls{HHU}. The majority of the measurements have been collected on the instrument with \gls{DMF} as a solvent, the remaining measurements have been made on the \gls{THF} instrument. The data has been exported as an ASCII file and plotted on OriginPro 2025 v10.2.
	\subsection{\glsentryshort{MALDI}}
	In order to receive information on the end groups of polymers, \gls{MALDI} can be measured by the \gls{CEMSA}. For this, the samples need to be in solution and an approximate molar mass is needed to set the measurement window. The concentration should be approximately \SI{1}{\milli\gram\per\milli\liter} and for the samples within this research work, \gls{THF} has been selected as a solvent.\\
